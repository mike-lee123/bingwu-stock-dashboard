# 9:30 強勢股即時選股

依「盤前看型態、試撮、族群 → 開盤後看守不守得住開盤價、量、相對大盤」的流程，用證交所公開資料自動篩選上市股票。

## 執行

```
pip install requests
python main.py              # 建議 8:25 前啟動，會一路跑到 9:30
python main.py --premarket  # 只看盤前候選名單
python main.py --once       # 立刻抓一次行情（測試用）
```

第一次執行要下載約 20 個交易日的收盤資料（約 1–2 分鐘），之後讀 `data/` 快取。
結果存在 `output/`：`YYYYMMDD_candidates.csv`（盤前）、`_live.csv`（盤中最新）、`_0930.csv`（9:30 定稿）。

## 條件對照

| 階段 | 條件 | 實作 |
|---|---|---|
| 盤前 | 收在最高附近 | (收−低)/(高−低) ≥ 0.8 且收紅，+1 分 |
| 盤前 | 帶量 | 前一日量 ≥ 5 日均量 1.5 倍，+1 分 |
| 盤前 | 突破前高 | 收盤 > 前 20 日最高，+1 分 |
| 盤前 | 籌碼 | 外資+投信前一日淨買 +1 分，連 2 日以上再 +1 分 |
| 盤前 | 流動性 | 5 日均成交值 < 1 億直接排除 |
| 盤前 | 族群、消息 | 手動寫進 `watchlist.txt`，不論分數都追蹤 |
| 8:30–9:00 | 試撮 | 走高／持平／平低／下修（從高點回落 >1%） |
| 9:00–9:30 | 守開盤 | 最低價不破 min(開盤, 平盤) 0.5% 以上，現價在開盤價附近之上；開高走低直接剔除 |
| 9:00–9:30 | 相對大盤 | 個股漲跌幅 − 加權指數漲跌幅 > 0 |
| 9:00–9:30 | 預估量 | 累計量 ÷ 時段累計比例 ÷ 5 日均量 ≥ 2 |
| 9:00–9:30 | 外盤 | 快照近似外盤比 ≥ 55% |
| 9:00–9:30 | 流動性 | 9:30 前累計成交值 ≥ 5000 萬（依時間比例） |
| 9:00–9:30 | 假突破 | 前 5 分鐘只標「觀察」；9:15 後要求 9:05 以來的低點守住支撐 |
| 9:00–9:30 | 漲停鎖單 | 成交在漲停價且無委賣時標「鎖漲停」與委買張數 |

結果分級：**強勢**＝守開盤、強於大盤、放量、流動性都符合，且 9:15 後回檔低點守住；**偏強**＝6 項中符合 4 項以上。

所有門檻都在 [config.py](config.py)。

## 限制

- 只涵蓋上市股票，不含上櫃。
- 證交所公開行情約有 5 秒延遲，每 20 秒輪詢一次，不是逐筆資料。外盤比是用快照推估，大單明細抓不到。
- 預估量的時段比例（`volume_curve`）是粗估值，建議用自己的分 K 資料校正。
- 試撮價讀取 `pz` 欄位，沒有時退回 `z`。
- 美股、ADR、費半與消息面需要自己判斷後寫進 `watchlist.txt`。

僅供研究參考，不構成投資建議。條件請先回測或小部位實測。
